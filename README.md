# আপনার ওয়েবসাইট — ব্যবহার নির্দেশিকা

এই ফোল্ডারে আছে:
- `index.html` — সাইটের মূল লেখা ও কাঠামো
- `style.css` — রঙ, ফন্ট, লেআউট
- `script.js` — মেনু ও ছোটখাটো ইফেক্ট
- `images/` — ছবি ও প্লেসহোল্ডার লাইন-আর্ট

## ১. লেখা পাল্টানো
`index.html` ফাইলটি যেকোনো টেক্সট এডিটরে (VS Code, Notepad) খুলুন। যেখানে
"Studio Ordos", প্রজেক্টের নাম, ঠিকানা, ইমেইল ইত্যাদি লেখা আছে, সরাসরি
বদলে দিন। HTML ট্যাগ (< > চিহ্নযুক্ত অংশ) ঘাঁটাঘাঁটি না করে শুধু লেখাগুলো বদলান।

## ২. নিজের ছবি যোগ করা
এখন `images/project-1.svg` থেকে `project-6.svg` — এই ৬টা লাইন-আর্ট ছবি
ডিফল্ট হিসেবে দেখাচ্ছে, যাতে আসল ছবি ছাড়াও সাইটটা খালি না দেখায়।

আসল প্রজেক্টের ছবি যোগ করতে:
1. আপনার ছবিটার নাম দিন ঠিক যেমন `project-1.jpg`, `project-2.jpg` ... `project-6.jpg`
2. সেগুলো `images/` ফোল্ডারে রাখুন (SVG ফাইলগুলো মুছবেন না — ওগুলো ব্যাকআপ হিসেবে থাকবে)
3. ব্যস — কোড এমনভাবে লেখা আছে যে `.jpg` ফাইল পেলে সেটাই দেখাবে, না পেলে লাইন-আর্ট দেখাবে

Hero (উপরের বড়) ছবির জন্য `images/hero.svg` বদলাতে চাইলে ফাইলের নাম
`hero.jpg` রেখে `index.html`-এ `src="images/hero.svg"` লাইনটা
`src="images/hero.jpg"` করে দিন।

## ৩. GitHub-এ আপলোড
1. GitHub-এ একটা রিপোজিটরি খুলুন, নাম দিন `আপনার-ইউজারনেম.github.io`
   (Public সিলেক্ট করবেন)
2. রিপোর ভেতরে **Add file → Upload files**
3. এই পুরো ফোল্ডারের ভেতরের সবকিছু (এই README বাদে, চাইলে রাখতেও পারেন)
   — `index.html`, `style.css`, `script.js`, আর পুরো `images` ফোল্ডার —
   একসাথে টেনে (drag & drop) দিন
4. **Commit changes**
5. রিপোর **Settings → Pages**-এ গিয়ে Branch হিসেবে `main` সিলেক্ট করে Save করুন
6. ২-৩ মিনিট পর সাইট লাইভ হবে: `https://আপনার-ইউজারনেম.github.io`

## ফাইলের নাম নিয়ে সাবধানতা
- ছবির নামে স্পেস বা বাংলা অক্ষর রাখবেন না — শুধু ইংরেজি, সংখ্যা, হাইফেন
- বড়/ছোট হাতের অক্ষর মিলিয়ে রাখুন (`Project-1.jpg` আর `project-1.jpg` আলাদা ফাইল হিসেবে গণ্য হয়)
